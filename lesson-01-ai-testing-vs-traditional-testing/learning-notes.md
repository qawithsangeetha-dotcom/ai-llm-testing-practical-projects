
# My Learning Notes – Lesson 01

## Topic
AI Testing vs Traditional Software Testing

## 1. Traditional Software Testing
Traditional software testing verifies whether an application works according to predefined business requirements and expected results.

Example:
- Enter valid login credentials.
- Verify successful login.
- Enter invalid credentials.
- Verify the appropriate error message.

## 2. AI Testing
AI testing evaluates AI-generated responses and behavior.

Important validation areas:
- Accuracy
- Relevance
- Consistency
- Clarity
- Safety
- Hallucination detection

## 3. Key Difference

Traditional testing often checks predefined expected results.

AI testing must also evaluate the quality and correctness of generated responses, which may vary in wording.

## 4. Practical Experiments

I executed five AI testing scenarios using ChatGPT.

1. Basic response validation
2. Accuracy validation
3. Consistency validation
4. Negative input validation
5. Clarity validation

## 5. Important Technical Learnings

- Selenium is primarily used for browser automation.
- JDBC supports database connectivity from Java applications.
- Regression testing verifies existing functionality after software changes.
- An API enables communication between applications or systems.
- AI should correct misleading or false assumptions instead of blindly agreeing.

## 6. My Learning Outcome

I learned that AI testing requires more than checking whether a response is generated.

A QA engineer must evaluate whether the response is accurate, relevant, consistent, and understandable.
