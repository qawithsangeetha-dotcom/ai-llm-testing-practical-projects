# Lesson 02 – Understanding LLMs

## 1. What is an LLM?
An LLM (Large Language Model) is an AI model trained on large amounts of text to understand and generate human-like responses.

## 2. Important Terms

### Token
A token is a small piece of text processed by an LLM. It can be a word, part of a word, or punctuation.

### Prompt
A prompt is the instruction or question given to an AI model.

### Context Window
The context window is the amount of text the model can consider during a conversation.

### Temperature
Temperature controls the randomness of generated responses. Higher values generally produce more varied responses.

### Hallucination
A hallucination occurs when AI generates incorrect or unsupported information.

## 3. QA Learning
As QA testers, we should validate:
- Accuracy
- Relevance
- Consistency
- Context retention
- Clarity

## 4. Key Learning
LLM testing requires checking not only whether the system responds, but also whether its response is correct, relevant, and useful.
